# Google Maps Lead Crawler

Search Google Maps by keywords, collect business name, phone, website, address. Perfect for B2B lead generation.

## Quick Start

1. Edit `keywords.txt` with your search terms (e.g. "leather bag manufacturer")
2. Double-click `run.bat`
3. Results saved in `output/` folder as Excel

## What it collects

- Business name
- Phone number
- Website
- Address
- Rating
- Google Maps link

No API key needed. Uses Playwright with real Chrome.
